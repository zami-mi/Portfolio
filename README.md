## 🚀 Descripción general

Este portfolio es un sitio web personal diseñado para reunir mi formación, conocimientos técnicos, proyectos e intereses profesionales.

Su objetivo principal es ofrecer una presentación clara de mi perfil como estudiante de informática y mostrar mi desarrollo y aprendizaje dentro del ámbito tecnológico.

## 🛠️ Tecnologías utilizadas

El proyecto utiliza tecnologías web para desarrollar su estructura, presentación visual y elementos interactivos.

| Tecnología | Aplicación |
|---|---|
| HTML5 | Estructura y organización del contenido |
| CSS3 | Diseño, estilos, animaciones y adaptación a dispositivos |
| JavaScript | Funcionalidades interactivas y comportamiento dinámico |

## 📂 Estructura del proyecto

El repositorio contiene los archivos principales del sitio web y los recursos utilizados para construir el portfolio.

```text
Portfolio/
│
├── index.html             # Página principal y estructura del sitio
├── style.css              # Estilos y diseño adaptable
├── translations.js        # Diccionarios de traducción (ES/EN)
├── main.js                # Lógica del sitio (idioma, menú móvil)
├── nuevaFoto.png          # Imagen personal
├── CV-ZamiraValentin.pdf  # Currículum vitae descargable
│
└── README.md              # Documentación del proyecto
```

## ☁️ Despliegue

El portfolio está preparado para publicarse como un sitio web estático mediante [Render](https://render.com/).

El proceso de despliegue conecta el repositorio de GitHub con Render, permitiendo actualizar automáticamente el sitio cada vez que se realizan cambios y se envían nuevos commits a la rama configurada.

## 🔭 Mejoras futuras

Este portfolio es un proyecto en constante evolución. Algunas de las mejoras que busco implementar son:

- Ampliar las secciones de proyectos y habilidades técnicas.
- Actualizar periódicamente el contenido a medida que adquiera nuevos conocimientos y experiencias.
